# A quick start with Saxophone Sight Reader

Start the app using the [setup instructions](../README.md#install-and-run).
Open it in Chrome or Edge, connect your Aerophone and click **Connect MIDI**.
Play a note and look at **Played** in the pitch monitor. If the note shows in
the wrong octave or key, use **Calibrate written C4** in **Instrument** and
play the C just below the treble staff.

Start with **Pitch drills** in the **Core** register if you want to work on a
small range. Try **Blues scale** or **ii–V–I arpeggios** once you are comfortable
with the notes. Use **Repeat passage** to play the same line again. Slur between
different pitches or articulate them separately. When a pitch repeats, give it
a fresh attack.

For written rhythm, switch to **Passage study** and play the **After Hours**
study. You can slow it down, listen to it, or work through a couple of bars.
The app’s **Help** page goes through the controls and MIDI file workflow.
