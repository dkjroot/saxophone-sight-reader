Connect your Aerophone

Use the supplied USB Type‑A cable to connect the Aerophone GO (AE‑05), then click Connect MIDI in Chrome or Edge and allow access. Choose the Aerophone in Input and play a note to check the pitch monitor.

For Bluetooth on a Mac, open Audio MIDI Setup → Window → Show MIDI Studio → Configure Bluetooth and connect to the AE‑05 with the instrument’s power switch on the Bluetooth symbol and its blue light blinking. In the browser, click Refresh MIDI if the device list is already open. If another device or app is connected to the Aerophone over Bluetooth MIDI, disconnect it first. Roland Aerophone GO manual · Apple’s Bluetooth MIDI instructions

With the Aerophone’s Transpose knob at C, start with Written pitch. If the played notes show the wrong pitch or octave, click Calibrate written C4 and play the C just below the treble staff. You can also select a sounding-pitch preset under MIDI pitch mapping. Use Learn lowest note and Learn highest note if you want to set your range by playing it.

If MIDI stops responding, check the browser’s site permissions, reconnect your cable or Bluetooth MIDI port and click Refresh MIDI. Clear input clears a stuck note. You can also use the pitch buttons with a mouse, a tap, or Space or Enter while a button is focused.

Pitch practice

Read the marked note on the treble staff. The pitch monitor shows what you played, and a higher or lower arrow helps you find the target. Mark target adds a diamond to the corresponding pitch button. Show note names gives you another way to check the written notes.

Use Pitch drills to work on recognition or try a scale, blues scale, bebop scale or ii–V–I line. Reading register limits the exercise to your chosen part of the range. For an easier starting point, try the core register and a whole-tone leap limit in Pitch drills.

Fluid progression accepts a new pitch as soon as you play it, including a slur. Articulate the same pitch again when it repeats. Release each note waits for the release before it moves the marker. Use Repeat passage for a fixed line, Continuous for more notes, or Stop at end for one pass. Scrolling and Look-ahead control how much you see as you play.

Passage study

Choose After Hours, Turnaround or a loaded passage. Play study lets you hear the line. Practise passage waits for your attacks and lets you correct short holds and missed notes. Use Speed, Entry beat and Exit beat to work on a small section.

Import MusicXML opens a single-voice treble part with ordinary or dotted notes, rests and ties. Use an uncompressed score-partwise file up to 256 KB. The app uses its written pitches. Files with DTD declarations, tuplets, grace notes or repeat traversal are outside the supported subset.

MIDI files and library

Load a built-in sax tune or choose a local MIDI file. Try the Swing Low, Sweet Chariot refrain for a compact range, Indiana for dotted rhythms or Blue Platform for a twelve-bar blues. Choose the section you want, then click Start practising this passage. The library tunes already use written sax pitch. For your own MIDI file, choose a melody track and use File pitch mapping if the file is in concert pitch.

Pitch practice uses the file’s attacks. Passage study adds derived rhythm on a 1/32-note grid and skips overlaps to keep a single line. Play source passage plays the selected original tracks. Download MIDI data (JSON) exports the original inspection. To reopen a saved passage, load the same file or library piece and choose it in Saved passages.

To look for more classical piano editions that can be used as melody sources, run python tools/discover_scores.py --composer ChopinFF --limit 8 with your project environment active. Open score-shortlists/mutopia.md for source and licence links. Download the MIDI file yourself, extract it if necessary, then use Choose MIDI file. Discovery only writes a shortlist.

Sound and progress

Use the Aerophone’s own sound or turn on Sound my playing for a local synth. Hear target plays the current pitch, and Metronome provides a click. Stop sound stops playback and the click.

Pitch practice tracks response time and first-try accuracy. Turn on Save history locally to keep those measurements in this browser. Imported music stays in memory for the session.
